# `machine_learning/features/`

Feature engineering for anomaly ML: turning raw or semi-structured logs into numeric/embedding inputs.

| File | Purpose |
|------|---------|
| `embeddings.py` | Embedding generation (e.g. for text chunks or log lines). |
| `vectorize.py` | Vectorization pipelines for model input. |
| `templates.py` | Feature templates / column definitions. |
| `__init__.py` | Package marker. |
